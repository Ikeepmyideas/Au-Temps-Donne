# 🌍 Au Temps Donné - Plateforme de Gestion Associative

Bienvenue dans le dépôt du projet **Au Temps Donné** ! Ce projet scolaire vise à créer une plateforme de gestion pour une association fictive, facilitant l'organisation des bénévoles, la logistique, et les activités sociales, avec une optimisation des tournées pour collecter et distribuer des dons. 🏢

## 📋 Objectifs du Projet

Cette plateforme permet de :
- **Gérer les bénévoles** : recrutement, plannings, affectations et formations 📅
- **Assister les bénéficiaires** : gestion des comptes et suivi des activités 💼
- **Optimiser les tournées de collecte et distribution** : génération automatique d’itinéraires PDF incluant carte et temps de trajet 🚗
- **Gérer les stocks et le suivi des services** : collecte, maraudes, aide aux personnes âgées 👴👵

## 🚀 Fonctionnalités Clés

- **🌐 Frontend en React** : Interface utilisateur dynamique et ergonomique.
- **⚙️ Backend en Node.js** : API REST fiable pour la gestion des données.
- **📊 Base de Données PostgreSQL** : Pour un stockage structuré et sécurisé.
- **🛣️ Générateur d'Itinéraires** : Calcul d'itinéraires optimisés avec carte en PDF.
- **🔍 Système de Ticketing en Python** : Suivi des erreurs et gestion des résolutions.
- **📦 Gestion de QR Code** : Pour le suivi des stocks.

## 🛠️ Technologies Utilisées

- **Frontend** : React
- **Backend** : Node.js
- **Base de Données** : PostgreSQL
- **Calcul d'Itinéraires** : Génération de PDF pour les circuits optimisés
- **Notifications** : Rappels push pour les bénévoles
